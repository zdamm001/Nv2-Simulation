# Nv2 Simulation

This repository contains a C++ conversion of the [N: The Way of the Ninja v2.0](https://www.thewayoftheninja.org/n.html) physics engine.

The project includes two main programs:

- a graphical simulation -> sim.cpp
- a replay section brute-forcer -> brute.cpp

The N v2.0 game was created and developed by [Metanet Software](https://www.metanetsoftware.com/) (Raigan Burns and Mare Sheppard)

ActionScript 3.0 (AS3) code used for conversion can be found in the official updated [Nv2.swf](https://thewayoftheninja.org/Nv2.swf).
